---
name: Historical startup attachments
description: Why older startup reports may have extracted data but no original file
---
Older versions deleted startup source files after successful extraction and set the file URL to null. Extracted data can therefore exist without a recoverable original PDF.

**Why:** Word exports need visual evidence, but a deleted original cannot be reconstructed faithfully from extracted JSON.

**How to apply:** Preserve new originals. Explicitly identify missing historical attachments and request re-upload rather than suggesting their pages can be recovered from analysis data.
